# Art and audio specs

All art in the project right now is **placeholder** generated by
`tools/gen_art.py`. It exists so the game is playable and the metrics are pinned
down. Replace any PNG with real art of the same size and nothing else changes.

```
python tools/gen_art.py      # sprites + tileset + the TileSet resource
python tools/gen_audio.py    # SFX and music loops
```

## Screen and grid

| | |
| --- | --- |
| Viewport | 426 × 240 (Mega Man X style widescreen-ish 16:9-ish) |
| Tile size | 8 × 8 |
| Screen in tiles | 53 × 30 |
| Texture filter | nearest, pixel snapping on |
| Physics tick | 60 Hz |

The default window is 1278 × 720 (3× scale), stretch mode `viewport`, aspect
`keep`.

frame indices. Keep the same 48-cell grid and you can redraw freely; change the
layout and update that one dictionary.

## The tileset resource is generated

`assets/tilesets/world_tileset.tres` is written by `gen_art.py`, not by hand. It
registers **every** atlas cell that has art (a cell with no tile definition
silently ignores `set_cell`) and attaches collision only to the cells listed in
the script's `SOLID` and `ONE_WAY` sets. If you redraw `tiles.png` by hand, either
keep the same cells or update those sets and re-run the script.

## Palette swap

The hero's armour recolours per weapon via
`src/shaders/palette_swap.gdshader`. It matches three suit tones and leaves the
gold trim, visor and skin alone:

| Role | Colour |
| --- | --- |
| `key_dark` | `#1A2E7A` |
| `key_mid` | `#3060D8` |
| `key_light` | `#6EA0FF` |

If you redraw the hero, either use those three blues for the suit or update the
`key_*` uniforms in `player.tscn`. `WeaponData.suit_primary` / `suit_secondary`
supply the replacements.

## Audio

`AudioManager` looks streams up by filename, so adding
`assets/audio/sfx/<name>.wav` is all that is needed. Missing sounds are silent
no-ops.

**SFX**: `shoot`, `shoot_mid`, `shoot_full`, `enemy_shoot`, `charge_loop`,
`charge_ready`, `hit`, `hit_big`, `deflect`, `explode`, `jump`, `land`, `slide`,
`hurt`, `player_death`, `hop`, `pickup`, `heal`, `one_up`, `denied`,
`menu_move`, `menu_confirm`, `pause`, `bar_fill`, `door`, `boss_appear`,
`boss_jump`, `boss_slam`, `boss_enrage`, `stage_clear`, `game_over`

**Music**: `title`, `stage`, `boss`, `stage_select`, `ending`

Music loops automatically (`AudioManager.play_music` sets the loop flag), so
`.ogg` files do not need loop points baked in.
