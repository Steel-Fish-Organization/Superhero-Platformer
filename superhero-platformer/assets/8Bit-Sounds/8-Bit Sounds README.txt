8-Bit Sounds - Audio Assets List
=====================

By Rea: Hi, thanks for downloading this item. All assets are completely free to use for both personal and commercial use.
		If you decide to use this pack for a public project, please let me know, I'd be happy :3

SONGS/
  Background music tracks for each level and the main menu.
  - Menu Theme
  - Menu Theme 2
  - Helpless
  - Shutter


SFX - PLAYER/
  Sounds tied to player actions.
  - Walk Hard/Soft 1-2  (footsteps on different surfaces)
  - Jump / Land Jump
  - Interact
  - Item Pickup
  - Player Damage


SFX - ENEMIES/
  Sounds for enemy behavior and robotic voicelines.
  - Enemy Damage 1-2 / Enemy Death
  - Enemy Shot / Enemy Step 1-3
  - Robot voicelines x3


SFX - WEAPONS/
  Organized by weapon action type.
  Shots/
  Shots (future guns)/
  Reloads/
  Grenade/


SFX - ENVIRONMENT/
  Ambient and world-interaction sounds.
  - Open Door / Close Door
  - Open Door (simple) / Close Door (simple)
  - Jigling Door (simple)
  - Elevator (short) / Elevator (long)
  - Bullet Ricochet
  - Idle Item Loop
  - Repair Kit
  - Siren Loop


SFX - UI/
  Interface feedback sounds.
  - Button Hover / Button Press
  - Open Menu / Close Menu
  - Hacking Loop / Hacking Complete / Hacking Fail
    Text Sounds/ - 4 files ( sfx for text boxes)
