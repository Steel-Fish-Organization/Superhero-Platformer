# Superhero Platformer

A Mega Man-style action platformer built in **Godot 4.5**, taking its controls
and structure from Mega Man 5/6 and its resolution and charge mechanics from the
SNES Mega Man X games.

The project lives in [`superhero-platformer/`](superhero-platformer/).

## Playing it

Open `superhero-platformer/project.godot` in Godot 4.5 and press **F5**.

| Key | Action |
| --- | --- |
| Arrows | move / climb |
| **X** | jump |
| **Z** | fire (hold to charge) |
| **C** | slide (or ↓ + jump) |
| **A** / **S** | previous / next weapon |
| **Enter** | pause + weapon menu |

Gamepads are mapped too (A jump, X fire, B slide, shoulders cycle weapons).

## What is here

- **426 × 240 viewport, 8 × 8 tile grid**, nearest filtering, pixel snapping.
- **Mega Man-tuned movement** — fixed jump arc with a variable cut, a
  fixed-duration slide that fits two-tile gaps, ladders, i-frames and knockback.
- **Charge weapon system** — tap / mid / full charge, entirely data-driven so the
  projectile can be swapped without touching code. See
  [docs/WEAPONS.md](superhero-platformer/docs/WEAPONS.md).
- **Nine stages** with a 3×3 stage select; the ninth sits in the centre and stays
  sealed until the other eight are cleared.
- **Bosses** with the classic intro (drop in, health bar fills, fight) and a
  per-weapon weakness table.
- **Three save files** with a file-select screen, stored as readable JSON.
- **Enemies, pickups, E/W-tanks, checkpoints, off-screen respawning**, room-based
  camera scrolling, hazards and moving platforms.

Stage 1 (*Foundry District*) is a designed level. Stages 2-9 are generated
blockouts — playable, and wired to their bosses and rewards, but meant to be
replaced with real design.

**`levels/sandbox.tscn` is a labelled greybox test level** — open it and press
**F6**. Jump-height and gap-width rulers, a slide tunnel, ladders, moving
platforms, one of every enemy and pickup, low-gravity and heavy rooms, and a
re-fightable boss. All weapons unlocked, and nothing there touches your save.
Extra keys: **R** respawn, **T** refill, **Y** take damage, **U** slow motion.

**All art and audio is placeholder**, generated by scripts so the metrics stay
consistent. Replacing any asset with the same dimensions requires no code change.

## Tools

Run from inside `superhero-platformer/`:

```bash
python tools/gen_art.py                                    # regenerate art + tileset
python tools/gen_audio.py                                  # regenerate SFX + music
godot --headless --path . --script tools/gen_weapons.gd    # rebuild the starter weapons
godot --headless --path . --script tools/gen_stages.gd     # rebuild stage_01..09 (overwrites!)
godot --headless --path . --script tools/gen_sandbox.gd    # rebuild the greybox test level
godot --headless --path . tools/smoke_test.tscn            # progression + save-file tests
godot --path . tools/screenshot_runner.tscn -- <scene> <out.png> [frames] [inputs] [warp]
```

`screenshot_runner` can drive the game with a scripted input sequence, which is
how the movement, charge shot and boss intro were verified.
